# Nebula N44

Asistente personal con IA para Windows que funciona en tu ordenador: lo
llamas con la voz y te responde con la suya, abre e instala programas, pone
música, busca en internet, te recuerda cosas y lleva tu correo y tu
calendario. Tú le pones el nombre.

**Gratis. Tus conversaciones se quedan en tu PC.**

## Descargar

Ve a [Releases](https://github.com/nicomr92008-rgb/NebulaN44/releases/latest)
y baja `NebulaN44-Setup-<versión>.exe`. No hace falta ser administrador.

La primera vez que se abre, descarga lo que necesita para tu equipo (el
motor de IA, el modelo y las voces), así que tarda unos minutos. Después se
actualiza sola cuando sale una versión nueva, si tú aceptas.

> Windows puede mostrar «Windows protegió su PC» porque el instalador aún no
> está firmado. Pulsa **Más información → Ejecutar de todas formas**. Baja
> el instalador solo de esta página.

## Requisitos

- Windows 10 (1809) o Windows 11, 64 bits
- 16 GB de RAM recomendados (funciona con 8 GB y modelos pequeños)
- Una gráfica NVIDIA, AMD o Intel acelera mucho; sin ella funciona con el procesador
- Unos 10 GB libres para el motor y los modelos
- Micrófono para hablarle

## Privacidad

Todo se procesa en tu ordenador. No hay cuentas, anuncios ni telemetría. La
voz en línea (Salomé) envía el texto de las respuestas a Microsoft para
leerlas en voz alta; puedes elegir una voz local en AJUSTES. Detalles en
[PRIVACIDAD.txt](PRIVACIDAD.txt).

## Importante
